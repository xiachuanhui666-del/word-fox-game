# 喂小狐学英语 (Word Fox Game)

儿童英语词汇互动学习游戏（移动端优先），针对小学三年级上册及启蒙英语设计。

## 🌟 核心特色

- **四维闭环**：听得懂（盲听选图）➔ 会读（自然拼读变色唱读 + 麦克风录音打分）➔ 会写（字母积木拼词）➔ 练得爽（拍泡泡 + 翻牌消消乐）。
- **小狐狸激励**：答题掉落松果 🌰，点击给小狐狸喂食，配合趣味咀嚼音效与表情反馈。
- **纯正母语发音**：接入网易有道母语美音高保真人声，支持 0.56x 乌龟慢速音节拼读。
- **国内无障碍网络**：100% 剥离海外 Google Fonts 与外部被墙 CDN，国内三大运营商手机毫秒级秒开。
- **免登免密**：无需注册任何账号，学习进度与错题本自动保存在手机本地。
